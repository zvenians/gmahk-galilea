# Galilea Creative Cinema V17.1.0

V17 adalah redesign struktural viewer publik. Fitur dan kontrak data V16 dipertahankan.

- Build viewer: `GALILEA-CREATIVE-CINEMA-17-1-0`
- Proxy Vercel: `GALILEA-VERCEL-BRIDGE-17.1.0`
- PDF: `GALILEA-QUARTERLY-PDF-17.1.0`
- Cache viewer: `v1700-*`
- Backend Apps Script: kompatibel dengan V16.0.0

Sorotan: navigasi layar penuh per kategori, layout bab film, loader sanctuary opening, header halaman bernomor bab, kontras dua mode teruji, dan share Renungan Pagi lengkap ke WhatsApp.
